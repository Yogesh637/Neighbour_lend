## Slide 2: The Problem
*   **Wasteful Consumption**: People buy tools/items they use only once (e.g., drills, camping gear).
*   **Storage Issues**: Cluttered homes with rarely used items.
*   **High Costs**: Purchasing quality equipment is expensive.
*   **Lack of Trust**: Existing platforms often lack community verification.

---

## Slide 3: The Solution - NeighbourLend
*   **Concept**: A web platform connecting neighbors to share resources.
*   **Mechanism**: Users can list items they own for rent and request items they need.
*   **Goal**: Promote sustainability, save money, and build community connections.

---

## Slide 4: Key Features
1.  **User Authentication**: Secure Login and Registration with JWT.
2.  **Marketplace Dashboard**: Browse available items with filters (Tools, Sports, etc.).
3.  **Posting System**: Users can upload images, set prices, and descriptions.
4.  **Booking Management**:
    *   **Renters**: Select dates and request items.
    *   **Owners**: Approve or Reject incoming requests.

---

## Slide 5: Technology Stack
*   **Frontend**: React.js, Vite, Axios (Responsive UI).
*   **Backend**: Java Spring Boot (REST API).
*   **Database**: MySQL (Data persistence).
*   **Security**: Spring Security + JWT Authentication.
*   **Styling**: CSS Modules (Modern, Clean Interface).

---

## Slide 6: System Workflow
1.  **Sign Up/Login**: User authenticates.
2.  **List Item**: Owner details item (e.g., "Drill Set", ₹50/day).
3.  **Search & Request**: Neighbor finds item -> Clicks "Rent" -> Selects Dates.
4.  **Approval**: Owner gets request -> Clicks "Approve".
5.  **Transaction**: Item status changes to "Taken" for those dates.

---

## Slide 7: Future Enhancements
*   **Payment Gateway**: Integrated payments (Stripe/Razorpay).
*   **Chat System**: Real-time messaging between lender and borrower.
*   **Rating System**: Review users and items after transactions.
*   **Map Integration**: View items on a map for proximity.

---

## Slide 8: Conclusion
**NeighbourLend** bridges the gap between ownership and access. It empowers communities to be more sustainable and economically efficient.
